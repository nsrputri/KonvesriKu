Bantuan & batasan

CSV ↔ JSON, DOCX ↔ TXT. Maksimal 2 MB, CSV/JSON 10.000 baris, teks UTF-8. CSV memakai koma; nilai tetap teks. JSON harus array objek datar dengan kunci yang sama. JSON bersarang ditolak; null menjadi sel kosong dan tipe JSON tidak dipertahankan saat kembali dari CSV. Periksa formula sebelum membuka CSV di spreadsheet.

DOCX mengambil paragraf dan tabel utama tanpa gambar, gaya, header/footer, atau tata letak. TXT membuat paragraf sederhana. Maksimal isi DOCX 20 MB setelah dibuka. .doc dan PDF tidak didukung.

Tarik lalu klik format lingkaran, atau lepas pada format yang cocok. Shift opsional; hanya bekerja di halaman ini. File dikirim ke server dan diproses di memori; aplikasi tidak sengaja menyimpan file ke disk. Tidak ada antrean persisten atau hasil lintas sesi. Hindari dokumen rahasia.
