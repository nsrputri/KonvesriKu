      Batas ukuran tergantung format. Teks harus UTF-8.

      File diunggah ke server lalu dikonversi lewat antrean. Setelah unggahan selesai Anda mendapat kode tugas: simpan kode itu. Halaman boleh ditutup, dan hasil bisa diunduh di sesi atau perangkat lain dengan kode tersebut. File asli dihapus begitu konversi selesai atau gagal; hasil dihapus otomatis 24 jam setelah selesai. Kode yang hilang tidak bisa dipulihkan karena tidak ada akun. Unggahan yang terputus harus diulang. Hindari dokumen rahasia.

      Hasil HTML selalu diunduh, tidak ditampilkan. Gambar dan resource luar tidak pernah diambil dari URL atau file lokal. PDF hasil pindai ditolak karena belum ada OCR. Jenis file dicek dari isinya sejauh formatnya memungkinkan; TXT, Markdown, dan LaTeX tidak selalu bisa dibedakan.
